# 四个创作起点

以下均为**整理者原创模板，未经 GPT‑6 实测**。它们不是任何收录案例的原始提示词，也不保证特定效果。替换方括号内容后使用；后续可以补充实测记录。

需要互联网上收集的提示词线索？见[社区提示词](community.md)。

<a id="3d"></a>

## 01 / 可编辑 3D 场景

```text
在 Blender 中制作 [主体/场景]，参考 [我提供的图片或说明]。
用途是 [渲染/游戏/打印]，尺寸或比例为 [要求]。
先说明几何结构与制作顺序，再完成模型、材质、灯光和相机。
对象按部件命名，保留可编辑结构，输出 .blend 与预览图。
按用途检查几何、法线和尺度；打印用途还需检查封闭性与薄壁。
查看实际渲染结果，修复明显问题，并说明未完成的细节。
```

<a id="web"></a>

## 02 / 有设计感的网页

```text
为 [用户群体] 制作一个 [网站类型]，核心任务是 [用途]。
风格参考 [参考资料]，内容使用 [提供的文案和素材]。
使用 [技术栈]，先确定信息层级、字体、颜色和页面结构，再实现。
完成 [关键交互]，兼顾手机、桌面与键盘操作。
在浏览器中实际运行，检查链接、表单、溢出与控制台错误。
交付源码、启动说明和最终截图；未接入的服务请明确标明。
```

<a id="video"></a>

## 03 / 程序化视频

```text
制作关于 [主题] 的 [时长] 秒视频，比例 [横屏/竖屏]。
使用 [视频制作工具]，素材来自 [我有权使用的文件]。
先写分镜，明确每段画面、字幕、节奏与音频，再完成制作。
输出可编辑工程和 MP4。核对字幕可读性、转场和音画同步。
逐段查看最终渲染，不用预览成功代替导出成功。
如需额外付费素材，先给出候选和价格供我确认。
```

## 04 / 可以真正游玩的原型

```text
使用 [引擎/技术栈] 制作一个 [类型] 游戏，核心机制是 [机制]。
先做灰盒：移动、目标、得分、失败和重新开始，实际玩通。
再根据 [视觉方向] 添加美术、音效和反馈，保持核心玩法稳定。
目标设备是 [设备]，控制方式为 [键盘/触屏/手柄]。
检查碰撞、卡住、胜负条件与重开流程，记录实际帧率和测试设备。
交付可运行版本、源码、启动说明及已知限制。
```
