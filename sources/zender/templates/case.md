# 案例标题

## 概览

- 分类：3D / Web / Video / Games（保留一项）
- 作者：原作者名称与主页
- 模型：准确名称；无法确认则写“待核实”
- 工具：实际使用的软件或服务；未知写“未公开”
- 来源类型：官方展示 / 作者自述 / 二手线索
- 核对日期：YYYY-MM-DD
- 复现状态：未复现 / 部分复现 / 已复现

## 作品与来源

填写原始链接、演示或工程链接、模型证据，以及该作品值得研究的具体原因。未知信息明确写出，不补造。

## 提示词

提示词状态：作者原文 / 作者摘要 / 整理者改写 / 未公开。

提供可引用的内容及出处，或写“原作者未公开完整提示词”。改写与原创模板不得声称是原始输入。

## 复现与局限

记录环境、输入、步骤、结果、失败点与证据链接。没有实测则写“尚未独立复现”。

## 权利与署名

标明素材权利人和许可；未知时写“许可未公开，仅链接引用”。
